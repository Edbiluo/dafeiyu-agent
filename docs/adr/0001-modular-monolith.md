# ADR 0001：采用模块化单体与独立 Worker

- **状态**：Accepted
- **日期**：2026-11-05

## 决策

首个可部署版本采用一个 API 服务和一个 Worker 服务，共享 TypeScript 工作区、数据库契约与任务队列。核心按领域模块隔离，不按微服务拆分。

## 原因

- QQ、网页和直播接入可以共享同一套会话与 Agent 核心。
- Worker 使记忆提取、摘要、嵌入和可靠消息投递不阻塞平台回调。
- 模块边界允许未来独立扩展 Agent、检索或平台服务。
- 相比完整微服务或 Temporal 集群，适合早期部署和调试。

## 后果

- 所有跨模块通信必须使用 `contracts` 中的稳定类型。
- 平台 Adapter 不可直接调用模型或数据库。
- 需要 PostgreSQL Outbox 和队列来保障异步任务可靠性。
- 当出现跨天、多审批、强恢复要求的工作流后，再评估 Temporal。
